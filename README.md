## Featured projects

### 🏎️ [Janus 2.0](https://github.com/aditeya08varma/Janus) ([live](https://janus-frontend-ncie.onrender.com/))
**Python | LangGraph | Redis | React 19 | Ragas**

- 🧠 Agentic RAG system that reasons over FIA technical regulations, with a metadata-filtered retrieval pipeline.
- 📊 Reached a **90% Answer Relevancy** score on a 20-query evaluation benchmark.
- 💾 Thread-isolated session memory across users using LangGraph and a Redis persistence layer.

### 🍎 [Darwin Server Runtime](https://github.com/aditeya08varma/darwin-server-runtime)
**Swift | C | launchd | Mach APIs | OpenTelemetry**

- ⚡ Native macOS process isolation runtime with a **55.4 ms cold spawn** (2.3x faster than Colima).
- 🪶 **2.9 MB idle footprint**, 160x smaller than Docker.
- 📡 Telemetry daemon that polls Mach APIs and exports traces over OTLP/HTTP.

### 🌐 [Traffic Analyzer and Caching DNS Proxy](https://github.com/aditeya08varma/traffic-analyzer-proxy)
**Python | POSIX Sockets | Scapy | PyTest**

- 🔌 Multi-threaded TCP proxy and DNS resolver built directly on raw POSIX sockets.
- 🚀 Repeat lookups drop from 45 ms+ to **under 1 ms** using a thread-safe LRU/TTL cache.
- 🧪 Fault-injection test suite that simulates socket exhaustion and malformed headers.

### 🎥 [Voyager](https://github.com/aditeya08varma/voyager)
**Kafka | PyFlink | Redis | Python**

- 📹 Real-time multi-camera video pipeline on a 6-partition Kafka topic, targeting **under 50 ms per frame**.
- 🧮 Perceptual embedding cache with a **75%+ hit rate**, cutting redundant neural network inference.
